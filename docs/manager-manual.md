# Manager Manual

## Where to Look

- `00_Master_Schedule`: complete consolidated schedule list
- `01_Monthly_View`: person-by-date calendar grid
- `02_Weekly_View`: current week and next week by person
- `03_Conflict_Report`: overlapping schedules for the same person and date
- `04_Availability`: configured workday availability status by person and date

## Interpreting Availability

- `AVAILABLE`: no schedule overlaps the configured workday
- `PARTIAL`: some scheduled time exists or timing is incomplete
- `BOOKED`: the configured workday is fully occupied or an all-day schedule exists
- `LEAVE`: leave status is recorded for that date

## Answering Repository Questions

Use repository data only. Always include:

- `Conclusion`
- `Reason`
- `Numbers`
- `Source`
- `Data Date`
